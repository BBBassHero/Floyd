# Tang Mega 60K 引脚分配

| 信号 | FPGA 引脚 | BANK 电压 | 方向 | 外设 | 备注 |
|---|---|---|---|---|---|
| sys_clk | V22 | 3.3V | 输入 | 系统时钟 | 50MHz |
| rst_n_in | Y12 | 1.5V | 输入 | 板载复位 | 低有效，内部上拉 |
| led0 | P19 | 3.3V | 输出 | 左侧 PMOD | 状态指示 |
| led1 | R19 | 3.3V | 输出 | 左侧 PMOD | 状态指示 |
| i2s_bclk | T21 | 3.3V | 输出 | I2S DAC | BCLK |
| i2s_lrclk | U21 | 3.3V | 输出 | I2S DAC | LRCLK |
| i2s_data | P16 | 3.3V | 输出 | I2S DAC | DATA |
| key0 | AA13 | 1.5V | 输入 | 板载按键 | 低有效，内部上拉 |
| key1 | AB13 | 1.5V | 输入 | 板载按键 | 低有效，内部上拉 |
| key_row[0] | Y21 | 3.3V | 输出 | 矩阵键盘 | 行扫描 |
| key_row[1] | Y22 | 3.3V | 输出 | 矩阵键盘 | 行扫描 |
| key_row[2] | AB21 | 3.3V | 输出 | 矩阵键盘 | 行扫描 |
| key_row[3] | AB22 | 3.3V | 输出 | 矩阵键盘 | 行扫描 |
| key_col[0] | AA20 | 3.3V | 输入 | 矩阵键盘 | 内部上拉 |
| key_col[1] | AA21 | 3.3V | 输入 | 矩阵键盘 | 内部上拉 |
| key_col[2] | AA19 | 3.3V | 输入 | 矩阵键盘 | 内部上拉 |
| key_col[3] | AB20 | 3.3V | 输入 | 矩阵键盘 | 内部上拉 |
| enc_a | R17 | 3.3V | 输入 | 旋转编码器 | 内部上拉 |
| enc_b | R18 | 3.3V | 输入 | 旋转编码器 | 内部上拉 |
| enc_sw | T18 | 3.3V | 输入 | 编码器按键 | 可选 |
